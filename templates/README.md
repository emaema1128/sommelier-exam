# データ作成テンプレート

スプレッドシートで開いて編集し、CSVで保存する。アプリにはArtisanコマンドで取り込む(未実装)。

| ファイル | 中身 |
|---|---|
| 解答用紙_用語マスタ.csv | 二次の解答用紙で選べる用語の一覧(白・赤、年度つき) |
| 品種プロファイル.csv | 品種の「型」。答案の各項目の模範解答と、推理ドリル用の描写 |
| 一次_問題.csv | 一次試験の4択問題 |

## 記入ルール

- 1つの欄に複数の用語を入れるときは `|` で区切る(例: `澄んだ|輝きのある`)。
- 品種プロファイルの用語は、**用語マスタにある表記と完全に一致させる**。取り込み時に一致しない用語はエラーにする。
- 白ワインは `味わい_タンニン分` と `評価_デカンタージュ` を空欄、赤ワインは `味わい_苦味` を空欄にする。
- `紛らわしい品種` は品種プロファイルの `id` を `|` で区切って書く(まだないidを書いてもよい)。
- `正解` は選択肢の番号(1〜4)。
- `公開状態` は `下書き` か `公開`。確認が済んだら `公開` にする。
- `確度`(用語マスタ)は `出典あり` か `要確認`。確認できたら `出典あり` に直す。

## サンプルについて

入っているデータはすべて**下書き**。品種プロファイルの模範解答は、対策サイトの「型」と一般的な品種の特徴から作った叩き台なので、内容を確認して直してから公開する。
