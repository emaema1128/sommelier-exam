# 二次試験(テイスティング)解答用紙 — Web調査メモ

- 調査日: 2026-10-20
- 位置づけ: **受験対策サイトの解説をもとにした再構成**。公式の解答用紙そのものではない。用語は年度ごとに少しずつ変わる。
- 目的: 品種プロファイルのデータの形を決めるため。実際の内容と大きく違う点があれば、daichiさんが判断して直す。

---

## 1. 試験の形式

| 項目 | ソムリエ | ワインエキスパート | 確度 |
|---|---|---|---|
| 出題数 | 5種類(ワイン3+ワイン以外の酒2)。ワインは白1・赤2 または 白2・赤1 | 5種類(ワイン4+ワイン以外の酒1)。ワインは通常 白2・赤2 | 対策サイト複数で一致 |
| 試験時間 | 40分 | 50分 | WEは公式の時間割で確認(11:50〜12:40) |
| 論述 | あり | なし | 対策サイト。問題数・時間は未確認 |
| 2026年度の実施日 | 9月28日(月) | 同左 | 公式 |

参考: 一次試験(CBT)は **120問・70分**(公式・ワインエキスパートの案内)。

## 2. 解答のしかた

- テイスティング・コメントは**すべて番号選択式のマークシート**。
- 選べる用語は**白ワイン用と赤ワイン用の別紙**(用語シート)に並んでいる。
- 項目ごとに**選ぶ個数が指定**される(1つだけの項目と、2つ以上の項目がある)。個数はワインごとに違う。
- **指定より多く選ぶと0点**になるとされる(要確認)。
- 正解の用語が指定の個数より多いことがある(例: 4つ選ぶ欄で正解が7つあり、そのうち4つ当たればよい)。**完璧でなくても、大きく外さなければ点になる**。
- 用語シートの用語のうち、実際に正解として使われるのは半分程度とされる。

## 4. アプリ設計への影響

調査結果は「飲まずに受かる」方針を後押しするものだった。

1. **配点の約7割はコメント**で、正解の用語も複数ある。品種を当てられなくても、品種の型どおりに選べば点が取れる。
2. **外観・香り・味わいを矛盾なく選ぶ**ことが勧められている。これは品種プロファイル(型)で教えられる。
3. **選びすぎは0点**とされるため、答案ドリルでは「指定の個数」を必ず守らせる。超えたら選べないUIにする。
4. 用語は年度で変わるので、**用語マスタをデータとして持ち、年度を付ける**(要件定義の方針どおり)。
